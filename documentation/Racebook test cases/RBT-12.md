# RBT\-12

### Edit mod - Preview image replaced - New image stored and previous image removed

**Description:** An owner replaces only the preview image, confirming the new file is stored, and the mod file is untouched.

**Preconditions:** Signed into an account that has already uploaded mod(s). A second valid image file is available. Currently on the My Mods page

**Flow of events:** Replacing one file during an edit (Microsoft Edge)

| Step | Action | Expected result |
| --- | --- | --- |
| 1 | Note the current preview image | Made note of current preview image for comparison |
| 2 | Edit the mod | Existing values and file names are pre-filled |
| 3 | Choose a different image as the preview image | The new file name replaces the previous one in the picker |
| 4 | Click the “SAVE CHANGES” button | The modal closes and a success toast is displayed |
| 5 | Observe the mod card | The new preview image is displayed |
