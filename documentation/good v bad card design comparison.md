# **<u>Readability</u>** 

Vivek’s Design - The title, creator and category are in the same bold italic orange font using the same size which doesn’t do well to create a clear hierarchy. As a result, the user cannot tell, at a glance, what is the most important piece of content on the card, meaning the user may have to take a moment to figure out where to start reading the card from. Additionally, italics should be used to make key pieces of information stand out or to place emphasis on something. 

Damian’s Design - The title being the largest, the creator text being smaller and the category being placed into a pill shape creates a clear hierarchy. This leans into how users are already conditioned to read content, by starting with what is most prominent and then working their way down the card. This makes for an easier experience as it goes with the grain by using a design choice that has been proven and battle tested. 

# **<u>Interaction Cues</u>** 

Vivek’s Design - The favourite icon is something rather generally unknown and some user may misinterpret what the action behind it is. As we saw, some may think it is a donate button instead of a favourite button. Additionally, the choice to use yellow is not one that was well executed and can contribute to visual noise. 

Damian’s Design - The heart shaped icon is a more conventional and battle tested approach when it comes to showing a favourite or like action. It matches what is seen on other platforms like Instagram which once again leans into what is already know and proven to work. This choice removes the learning curve for new users. 

## **<u>UX</u>** 

Vivek’s Design - All the elements on the card “shout” at the user, and since this is true for all the elements nothing stands out which means the user isn’t guided on how they should read the information. Additionally, the zig-zag pattern created by the text placement makes for a less than effortless experience when processing the content. 

Damian’s Design - follows the standard visual hierarchy principle (size/weight signals importance) and the content not competing with each other makes for an effortless reading and processing experience. The icon and color choices lean into battle tested conventions which lowers the learning curve.
