# Racebook Problem Statement

Players of the 2010 arcade racing game “Blur” have recently found a way to create and use custom visuals in the game. Currently, these custom files (mods) are stored on a dedicated channel in the “Blur Community” Discord server. This manner of storage has proven a little inconvenient in terms of searching and browsing, and Discord’s file size limit, which is 8MB at the time of writing this.

This application aims to provide a better, more tailored storage solution for player made mods where searching will be made a painless experience, and mod creators won’t have to be bound by Discord’s file size limit. 


**Out of scope:** Additionally, as an acknowledgement to the more competitive players, this application will also allow users to view their current game stats and how their stats have increased in a given period of time. The start and end of this period can be specified by the user.
